Place the cabin escape plan PDFs in this folder using these filenames:

- safety_brief.pdf
- state-escape-plan.pdf
- port-vip-escape-plan.pdf
- starboard-vip-escape-plan.pdf
- port-twin-escape-plan.pdf
- starboard-twin-escape-plan.pdf

The Safety tab in index.html reads these files from a static SAFETY_DOCUMENTS
list and opens them directly from this folder using relative plans/*.pdf paths.
